🚀 Welcome to **MozMusic 1.0.9**! We've packed this update with massive UI upgrades and under-the-hood improvements.

### ✨ What's New
* **Infinite Recommendations**: A completely revamped, hyper-responsive "Up Next" engine that instantly queues similar tracks.
* **Sleek Navigation Overlays**: New iOS-style animated glassmorphic tooltips in the player to quickly jump to similar artists and albums.
* **Premium Details Grid**: A beautifully redesigned Song Info menu using frosted 2-column grids with high-fidelity file metrics.
* **Studio Quality Badges**: Added premium LOSSLESS, AAC, and interactive LYRICS indicator pills right above your playback slider.
* **Dynamic Theming**: Our UI panels now intelligently blend and adapt to your specific theme colors for a deeply personalized look.
* **Seamless Interactions**: Resolved gesture conflicts for buttery-smooth scrolling and swiping across the app.

### 🛠️ Fixes & Security
* **Enhanced Cloud Security**: Upgraded Firestore security rules to lock down databases and keep your profile and playback telemetry completely safe.
* **UI Redesign**: Fully replaced the rigid "Force Update" screen with an expansive, glassmorphic scrollable panel that dynamically supports markdown.
* **Stability Upgrades**: Crushed various navigation bugs, typecast crashes, and nested scroll issues for a flawless listening session.
